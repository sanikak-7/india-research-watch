# India Research Watch data

These CSV files are the datasets currently displayed by the website.

| File | Contents | Source |
| --- | --- | --- |
| `industry-rd-expenditure-fy2023-24.csv` | Industry group combined R&D expenditure for FY 2023-24 | India R&D Expenditure FY2019-20 to FY2023-24 workbook, Industry Combined sheet |
| `funding-by-sector.csv` | R&D expenditure by Central, State, Private, and Higher Education sectors | S&T Indicators Tables 2025-26, Table 1, p. 18 |
| `national-rd-trend.csv` | National R&D expenditure and R&D as a percentage of GDP | S&T Indicators Tables 2025-26, Table 3, p. 20 |
| `rd-workforce-by-performing-sector-2023-24.csv` | Full-time-equivalent R&D workforce and women workforce by non-overlapping performing sector | S&T Indicators Tables 2025-26, Tables 21-22, pp. 46-47 |
| `india-research-output-by-sector.csv` | Annual India-affiliated scientific publications and citation impact by OpenAlex primary topic and subfield | OpenAlex Works API; generated by the reproducible pipeline below |

Rows marked with `*` are estimates based on sector-wise CAGR, as noted in the source tables.

## India scientific-output pipeline

`india-research-output-by-sector.csv` is generated from the OpenAlex Works API. A work is included when OpenAlex records at least one authorship institution with `country_code == "IN"`; author nationality is not used. Each retained work is counted once and only in its `primary_topic` and primary subfield, preventing sector overlap.

The default range is 2000–2026 and is configurable without editing code:

```powershell
$env:OPENALEX_API_KEY = "your-free-openalex-key"
# Optional: $env:OPENALEX_MAILTO = "you@example.org"
npm run data:openalex
```

Create the required free API key at <https://openalex.org/settings/api>. The optional `OPENALEX_MAILTO` value is sent only with API requests and is not written to public data. Set `START_YEAR` and `END_YEAR`, or pass `-- --start-year 2010 --end-year 2025`, to change the range. Run `npm run data:openalex:refresh` to intentionally replace the resumable compressed cache in `.cache/`.

The pipeline includes OpenAlex `article`, `review`, and `conference-paper` works, excludes records marked retracted, and fetches only the fields needed for the output. It uses `publication_year`, `cited_by_count`, `primary_topic`, and OpenAlex's `citation_normalized_percentile` top-10% and top-1% flags. It does not create a custom citation-normalization model.

The CSV contains one observed `year × primary topic × primary subfield` row with publication counts, total/mean citations, and global top-10%/top-1% counts and shares. It is accompanied by metadata and a quality report that document query configuration, per-year unique works, duplicate IDs, missing classification/percentile data, Unclassified shares, and sector-total validation.

Citation counts for recent publications are immature. In particular, 2026 is a partial calendar year and should be interpreted cautiously; the pipeline preserves OpenAlex's reported counts and percentile indicators without artificial correction.
